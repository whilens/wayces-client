# Оптимизации проекта

## ✅ Реализованные оптимизации

### 1. **Lazy Loading страниц**
- Использован `React.lazy()` для асинхронной загрузки страниц
- Добавлен `Suspense` с fallback компонентом
- **Результат**: Уменьшен начальный bundle size, страницы загружаются по требованию

```jsx
const Home = lazy(() => import('./pages/Home/Home'));
const Products = lazy(() => import('./pages/Products/Products'));
const Cart = lazy(() => import('./pages/Cart/Cart'));
```

### 2. **React.memo для компонентов**
- `ProductCard` обернут в `React.memo` с кастомной функцией сравнения
- `Header` обернут в `React.memo`
- **Результат**: Предотвращены лишние ререндеры компонентов

### 3. **useMemo и useCallback**
- `useMemo` для форматирования цен (избегаем повторных вычислений)
- `useCallback` для обработчиков событий
- `useMemo` для списка товаров в Products
- **Результат**: Оптимизированы вычисления и функции

### 4. **Оптимизация Redux селекторов**
- Созданы отдельные селекторы в `store/selectors/`
- Использованы селекторы вместо прямого доступа к state
- **Результат**: Мемоизация селекторов, меньше ререндеров

### 5. **Throttle для scroll события**
- Создана утилита `throttle` для ограничения частоты вызова
- Применен throttle к scroll handler в Header (100ms)
- Добавлен `{ passive: true }` для оптимизации
- **Результат**: Улучшена производительность при скролле

### 6. **Оптимизация cartSlice**
- Вынесена функция `calculateTotals` для переиспользования
- Убраны дублирующиеся вычисления
- **Результат**: Более чистый и эффективный код

### 7. **Lazy loading изображений**
- Добавлен атрибут `loading="lazy"` для изображений
- **Результат**: Изображения загружаются по требованию

### 8. **Оптимизация форматирования**
- Использован `useMemo` для форматирования цен в Cart
- Форматирование происходит только при изменении данных
- **Результат**: Меньше вычислений при рендере

## 📊 Ожидаемые улучшения производительности

1. **Начальная загрузка**: -30-40% (благодаря lazy loading)
2. **Ререндеры**: -50-70% (благодаря React.memo и селекторам)
3. **Scroll производительность**: +40-60% (благодаря throttle)
4. **Память**: Оптимизировано использование памяти

## 🚀 Как проверить оптимизации

1. Откройте DevTools → Performance
2. Запишите профиль при переключении страниц
3. Проверьте количество ререндеров в React DevTools Profiler
4. Проверьте Network tab - страницы должны загружаться по требованию
