## Типы вариантов

### 1. `color` - Цвет
- Отображается как цветные квадраты
- Требует `colorCode` (HEX)
- Может иметь свои изображения

### 2. `button` - Кнопки
- Отображается как кнопки с текстом
- Для размеров, памяти, RAM и т.д.

### 3. `select` - Выпадающий список
- Для вариантов с большим количеством опций
- Например, гарантия, доставка

## Процесс добавления товара

### Вариант 1: Пошаговый мастер

1. **Шаг 1: Основная информация**
   - Название, категория, цена, описание

2. **Шаг 2: Характеристики**
   - Общие характеристики модели

3. **Шаг 3: Варианты**
   - Добавление типов вариантов
   - Добавление значений для каждого типа

4. **Шаг 4: Комбинации**
   - Автоматическая генерация всех комбинаций
   - Редактирование цен и количества на складе

5. **Шаг 5: Изображения**
   - Загрузка изображений для вариантов

### Вариант 2: Единая форма

Все поля на одной странице с разделами.

## JSON структура для отправки на сервер

```json
{
  "name": "Смартфон iPhone 15 Pro Max",
  "slug": "iphone-15-pro-max",
  "basePrice": 129999,
  "categoryId": 1,
  "description": "Описание...",
  "specifications": {
    "display": "6.7\"",
    "processor": "A17 Pro"
  },
  "defaultImage": "https://...",
  "variants": [
    {
      "variantKey": "color",
      "variantName": "Цвет",
      "variantType": "color",
      "displayOrder": 1,
      "options": [
        {
          "optionKey": "color-natural",
          "optionValue": "Натуральный титан",
          "colorCode": "#8B7355",
          "priceModifier": 0,
          "images": ["url1", "url2"],
          "isDefault": true,
          "stockQuantity": 10
        }
      ]
    },
    {
      "variantKey": "storage",
      "variantName": "Память",
      "variantType": "button",
      "displayOrder": 2,
      "options": [
        {
          "optionKey": "storage-256",
          "optionValue": "256 ГБ",
          "priceModifier": 0,
          "isDefault": true,
          "stockQuantity": 15
        }
      ]
    }
  ],
  "autoGenerateCombinations": true
}
```

## Валидация

1. **Обязательные поля:**
   - Название, slug, базовая цена, категория

2. **Уникальность:**
   - Slug должен быть уникальным
   - Ключи вариантов должны быть уникальными в рамках товара
   - Ключи значений вариантов должны быть уникальными в рамках типа варианта

3. **Логика:**
   - Хотя бы один вариант должен иметь значение по умолчанию
   - Цена комбинации = базовая цена + все модификаторы
   - Количество на складе не может быть отрицательным

## Массовые операции

- Массовое изменение цен комбинаций
- Массовое изменение количества на складе
- Массовая активация/деактивация комбинаций
- Импорт товаров из CSV/Excel
