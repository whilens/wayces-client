# Архитектура проекта интернет-магазина

## 📁 Структура проекта

```
client/src/
├── components/          # Переиспользуемые компоненты
│   ├── Header/
│   ├── ProductCard/
│   └── ProtectedRoute/
├── pages/              # Страницы приложения
│   ├── Home/
│   ├── Products/
│   └── Cart/
├── store/              # Redux store
│   ├── slices/         # Redux slices
│   │   ├── cartSlice.js
│   │   ├── productsSlice.js
│   │   ├── authSlice.js
│   │   └── uiSlice.js
│   └── store.js
├── services/           # API сервисы
│   └── api.js
├── hooks/              # Кастомные хуки
│   └── redux.js
├── utils/              # Утилиты и константы
│   ├── constants.js
│   └── helpers.js
└── App.js
```

## 🎯 Best Practices

1. **Компоненты**: Каждый компонент в своей папке с CSS
2. **Redux**: Использовать createAsyncThunk для async операций
3. **Роутинг**: Все маршруты в constants.js
4. **API**: Все запросы через services/api.js
5. **Стили**: Использовать rem единицы
6. **Именование**: BEM методология для CSS классов
